# brandyemurray.github.io

Source for my portfolio site, built with Jekyll and served by GitHub Pages.

- `index.html`: home page
- `_posts/`: project write-ups (posts with `published: false` are drafts and don't appear)
- `_data/`: experience and skills shown on the home page
- `assets/css/site.css`: all styling
- `doc/`: resume and slide walkthroughs
